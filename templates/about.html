About InsightForge AI

An AI-powered research assistant that reads, analyzes, and discusses your documents with you.

What it does

InsightForge AI evolved from an NLP and agentic-AI learning project into a full-stack research assistant. It combines document processing, natural language processing, and a conversational LLM so you can upload a paper, spreadsheet, or image and immediately start asking questions about it — grounded in the actual content, not guesswork.

Technology

Flask + SQLAlchemy backend
LangChain + Groq (Llama 3.3) for reasoning
spaCy, KeyBERT for NLP extraction
Sentence Transformers + FAISS for retrieval
PyMuPDF, python-docx, pandas for document parsing
Vanilla JS + Web Speech API on the frontend

Architecture

The backend is organized into clear layers: Flask blueprints handle HTTP requests, service modules contain business logic, and a dedicated AI/NLP layer manages embeddings, retrieval, and LLM calls. Every conversation, document, and message is scoped to the account that created it.
